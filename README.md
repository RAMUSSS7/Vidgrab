# VidGrab

أداة بواجهة رسومية لتحميل الفيديوهات من TikTok وInstagram وFacebook وTwitter/X وYouTube وأكثر من 1000 موقع، مبنية على [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## المميزات
- الصق رابطاً أو عدة روابط (رابط في كل سطر)
- اختيار الجودة: أفضل جودة، 1080p، 720p، 480p، أو صوت فقط MP3
- شريط تقدم وسرعة التحميل وزر إلغاء
- دعم كوكيز المتصفح للفيديوهات التي تحتاج تسجيل دخول
- FFmpeg مدمج داخل ملف exe، لا يحتاج تثبيت أي شيء

## الاستعمال (ملف exe)
1. ادخل على تبويب **Releases** أو **Actions** في المستودع ونزّل `VidGrab.exe`.
2. شغّله، الصق الرابط، اضغط **تحميل**.
3. الفيديوهات تُحفظ في `Downloads/VidGrab` افتراضياً.

## التشغيل من الكود
```
pip install -r requirements.txt
python app.py
```
بدون exe تحتاج [FFmpeg](https://ffmpeg.org/download.html) في PATH لدمج الصوت والصورة وتحويل MP3.

## بناء exe
يبنيه GitHub Actions تلقائياً عند كل push، وكل اثنين بأحدث yt-dlp. لإصدار رسمي:
```
git tag v1.0.0
git push origin v1.0.0
```

## ملاحظات
- **Instagram وFacebook**: الفيديوهات الخاصة أو التي تطلب دخولاً تحتاج اختيار متصفحك في خانة "كوكيز المتصفح" (أغلق المتصفح أولاً).
- إذا توقف التحميل من منصة معينة، غالباً المنصة غيّرت نظامها؛ نزّل أحدث إصدار.
- قوائم التشغيل (playlists) غير مفعّلة، يُحمَّل الفيديو المرتبط بالرابط فقط.

## تنبيه قانوني
الأداة للاستعمال الشخصي فقط. لا تُعد رفع فيديوهات الآخرين أو تبيعها، والتزم بحقوق الملكية وشروط استخدام كل منصة. المطوّر غير مسؤول عن سوء الاستعمال.
