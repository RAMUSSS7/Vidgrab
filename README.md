# VidGrab

أداة بواجهة داكنة لتحميل الفيديوهات من TikTok وInstagram وFacebook وTwitter/X وYouTube وأكثر من 1000 موقع، مبنية على [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## المميزات (v1.1)
- الصق رابطاً أو عدة روابط (رابط في كل سطر)، أو انسخ رابطاً وافتح البرنامج فيلصقه لوحده
- **معاينة** قبل التحميل: صورة مصغرة والعنوان والمدة
- اختيار الجودة: أفضل جودة، 1080p، 720p، 480p، أو صوت فقط MP3
- **توافق أعلى (H.264)**: الفيديو يشتغل على أغلب الجوالات والمشغلات
- تحميل **قائمة تشغيل كاملة** (اختياري) و**الترجمة** (اختياري)
- تحميل أسرع بأجزاء متوازية
- **سجل التحميلات**: فتح الملف، إظهاره في المجلد، أو إعادة تحميله
- يتذكر إعداداتك (المجلد والجودة والخيارات)
- دعم كوكيز المتصفح للفيديوهات التي تحتاج تسجيل دخول
- FFmpeg مدمج داخل ملف exe، لا يحتاج تثبيت أي شيء

## الاستعمال (ملف exe)
1. نزّل `VidGrab.exe` من تبويب **Releases** أو **Actions** في المستودع.
2. شغّله، الصق الرابط، اضغط **تحميل**.
3. الفيديوهات تُحفظ في `Downloads/VidGrab` افتراضياً.

## التشغيل من الكود
```
pip install -r requirements.txt
python app.py
```
بدون exe تحتاج [FFmpeg](https://ffmpeg.org/download.html) في PATH لدمج الصوت والصورة وتحويل MP3.

## بناء exe
يبنيه GitHub Actions تلقائياً عند كل push، وكل اثنين بأحدث yt-dlp. لإصدار رسمي:
```
git tag v1.1.0
git push origin v1.1.0
```

## أين تُحفظ الإعدادات والسجل
في `%APPDATA%\VidGrab` (ملفا `settings.json` و`history.json`). احذف المجلد لإعادة الضبط.

## ملاحظات
- **Instagram وFacebook**: الفيديوهات الخاصة أو التي تطلب دخولاً تحتاج اختيار متصفحك في خانة "كوكيز المتصفح" (أغلق المتصفح أولاً).
- إذا توقف التحميل من منصة معينة، غالباً المنصة غيّرت نظامها؛ شغّل الـ workflow يدوياً (Run workflow) لبناء نسخة بأحدث yt-dlp.

## تنبيه قانوني
الأداة للاستعمال الشخصي فقط. لا تُعد رفع فيديوهات الآخرين أو تبيعها، والتزم بحقوق الملكية وشروط استخدام كل منصة. المطوّر غير مسؤول عن سوء الاستعمال.
